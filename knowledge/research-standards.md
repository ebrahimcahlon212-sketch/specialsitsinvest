# Research standards

This file consolidates the repository instructions and build review findings. It does not reconstruct missing investor feedback or supply facts about a deal.

- Use primary documents, with PDF file page numbers or text line locators. Re-read the cited source. Inspect table images before using their figures.
- Keep sourced facts separate from judgements. Do not substitute a submission, letter or filing date for a company announcement timestamp.
- Compute results from identified inputs in code. Recompute every published metric. Missing data, uncertain timing and unpriced events must remain visible.
- Do not infer completeness from an extractor's own list of evidence or calculations. Reconcile against independently collected inventories and the output actually published.
- Historical listing, first-product status and pre-news market value need contemporaneous evidence. Keep acquired and delisted companies in the population.
- Report-derived prices and synthetic benchmarks are test fixtures, not independent acceptance evidence.
- Research steps remain exempt from publication gates. Existing command results remain compatible, with actual detected failures on stderr. New publication commands fail closed.
- Respect the investor account and tax profile. Never place orders. Missing source evidence is a gap, not permission to estimate silently.
