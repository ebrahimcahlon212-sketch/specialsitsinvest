# Write the first draft

Write the first draft of a special situations report on the deal in the folder listed under "Files for this run".

1. Read the filings index and the market data file, then the document map if one is listed. Read every section the map marks for reading in full, from start to finish, before you write.
2. Decide which situation type this is and open the matching checklist in the checklists file. If the deal mixes types, use every checklist that applies.
3. Work through the checklist against the filings. For each item that applies, find the answer and note its citation. Items that apply but are not answered in the filings go in section 10, Open questions.
4. Write the report using the report template, with its headings in the same order. Section 11 should read "Pending sizing step." Leave out section 12, because it is added in the final version.
5. Check every figure in the Key numbers table against its source page. You don't need to work out returns per year, break-even prices or proration scenarios, because a Python calculator does that after the reviews. Give each input it needs clearly, with a citation, including your closing dates and probabilities.

Put the complete report between the output markers.
