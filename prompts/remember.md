# Keep the lessons from this deal

The research on this deal is listed under "Files for this run", along with the knowledge notebook's index. Your job is to pick out lessons worth carrying into future deals and add them to the notebook.

A good lesson is reusable. It might be how a regulator behaves, a precedent and what it decided, a base rate, a contract term to look for, a method that worked, or a data source that misled. Facts that only matter for this deal, such as its share price, do not belong, unless they illustrate a general point.

Read the notebook's index and the notes that relate to this deal first, so you add what is new rather than repeating what is already there. If an existing lesson turns out to be wrong or out of date, add a correction rather than repeating it.

Write one line of JSON per lesson, with these keys.

| Key | What to put in it |
|---|---|
| note | The name of an existing note from the index, such as uk-merger-control, or a new short name in lower case with hyphens |
| title | For a new note only, a plain title |
| topics | For a new note only, a few comma-separated topics |
| action | add, or correct if it corrects an earlier lesson |
| lesson | The lesson in one to three plain sentences, specific enough to act on |
| source | The document and page, or the address and date, that supports it |
| confidence | high, medium or low |

List at most 10 lessons, the most useful first. If nothing new is worth keeping, write no lines at all. Do not use em dashes.

Put the JSON lines, and nothing else, between the output markers.
