# Update the report for new documents

The files under "Files for this run" include the previous final report, the calculator results and a list of new documents that arrived after that report was written.

1. Read every new document in full.
2. Decide what each one changes. Check the previous report's claims that the new documents touch against the pages, but don't reread old documents unless a new one points you to them.
3. Write the full updated report using the report template. Keep what is still right and change what the new documents change.
4. Right after the plain English section, add a section headed "## What changed since the last report". List each change in a sentence or two with its citation, and say whether it makes the trade better or worse.
5. Use the calculator results for spreads, returns per year, probabilities the market implies, break-even prices and proration scenarios, and don't redo that arithmetic yourself.

New research files may also be listed, such as a store overlap analysis, a competition assessment, a fundamentals report or answers to questions. Treat them as new information in the same way. Where they change a probability, state the assumptions behind the new figure and show how the conclusion changes if those assumptions move. Keep proximity separate from competitive harm, and present timetables as scenarios rather than certainties.

Put the complete updated report between the output markers.
