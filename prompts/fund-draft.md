# Write the fundamentals report

Write a first-principles report on this business, using the fundamentals template listed under "Files for this run". The goal is to understand how the business actually makes money and what it is worth on its own, independent of any offer, so the reader can judge the offer price and the downside if a bidder walks away.

1. Read the filings index. Start with the latest annual report's strategic report, segment note, revenue note and financial statements, then the latest half-year results and trading updates.
2. Build the revenue equation for section 2 from the company's own disclosures, such as fleet size, utilisation, rates, volumes or customer numbers. If a driver isn't disclosed, say so rather than inventing it.
3. For section 4, reconcile adjusted figures to statutory ones, and flag one-off items, acquisitions, currency effects and capitalised costs that flatter or hurt the trend.
4. For section 10, set out your assumptions for each case plainly and cite what supports them. Don't compute the valuation yourself, because a Python calculator does that after the reviews.
5. Cite every figure. Where you use general knowledge rather than a filing, mark it "Not from the filings".

Write in plain language, explain any technical term the first time you use it, and do not use em dashes.

Put the complete report between the output markers.
