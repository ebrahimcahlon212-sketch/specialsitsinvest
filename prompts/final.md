# Write the final report

Other models have reviewed the draft report listed under "Files for this run". Produce the final report.

1. Read the draft and every review listed below.
2. For each point a reviewer raised, open the cited page yourself and decide who is right. Do not accept a correction without checking the page, and do not dismiss one without checking it either.
3. Use the calculator results listed below for spreads, returns per year, the chance of closing the market implies, break-even prices and proration scenarios. Don't redo that arithmetic yourself. If an input the calculator used looks wrong, say so in section 12.
4. Write the final report using the report template, fixing what did not hold up and adding the missing items that matter.
5. Fill in section 12 with every point where a reviewer disagreed with the draft, including the ones you rejected, and cite the page that settled each one.
6. Section 11 should read "Pending sizing step." unless the draft already has sizing content.

Put the complete final report between the output markers.
